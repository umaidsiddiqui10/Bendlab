# Model v2 candidates — changes and results, 15 Oct 2026

**Scope:** two candidate extensions to the BendLab model, tested against
the known ZT9 limitation. Contributed via pull request #1; reviewed,
independently verified, and corrected where noted below. The original
model (`sim.py`) is unchanged, and both candidates reduce to it exactly
at their default settings (verified in `check_model_v2.py`).

---

## 1. Proprioceptive term (`sim_gamma.py`)

Adds an autostraightening stimulus following Bastien et al. (2012),
reduced to a single tip angle:

```
tau * dr/dt = k * sin(phi - theta) - gamma * theta - r
```

**Test:** ZT9-1 refitted with gamma fixed on a grid {0, 0.5, 1.0, 1.5, 2.0}
and free, all other parameters fitted (script: `gamma_zt9_test.py`).

**Result (negative):** at gamma = 0, RMSE = 6.759 deg (the official static
fit). Forced gamma > 0 worsens the fit; with gamma free the optimiser
returns it to ~0 and RMSE is unchanged. A theta-proportional
straightening term in a single-angle model does not repair the ZT9
two-phase shape. This constrains, but does not eliminate, curvature-space
proprioception (Bastien et al.'s formulation acts on local curvature,
which a lumped tip angle cannot represent faithfully).

## 2. Circadian gating of sensitivity (`sim_clock_gamma.py`)

Modulates the light sensitivity with a 24 h clock, following the gating
reported by Atamian et al. (2016):

```
k_eff(t) = k0 * (1 + a * cos(2 * pi * (ZT - phase) / 24)),  ZT = ZT_start + t
```

**Test A (in-sample, per-plant clock):** the six ZT9 plants refitted with
a and phase free per plant (script: `clock_validation.py`, Part A).

| Plant | Static RMSE | Free-clock RMSE |
|---|---|---|
| ZT9-1 | 6.76 | 3.20 |
| ZT9-2 | 4.83 | 1.80 |
| ZT9-3 | 2.89 | 0.86 |
| ZT9-4 | 1.95 | 1.01 |
| ZT9-5 | 1.20 | 0.84 |
| ZT9-6 | 1.38 | 1.20 |

All six improve; fitted phases cluster at 7.6–10.7 h. Because a and phase
are free per plant, this alone does not distinguish a circadian mechanism
from flexible curve fitting.

**Test B (held-out, shared clock):** a single shared (a, phase) fitted on
the 42 non-ZT9 plants only (a = 0.47, phase = 8.14 h), then applied to
ZT9 with only the four standard parameters fitted per plant (script:
`clock_validation.py`, Part B).

| Plant | Static RMSE | Shared-clock (held out) |
|---|---|---|
| ZT9-1 | 6.76 | 4.85 |
| ZT9-2 | 4.83 | 3.07 |
| ZT9-3 | 2.89 | 1.60 |
| ZT9-4 | 1.95 | 1.12 |
| ZT9-5 | 1.20 | 0.89 |
| ZT9-6 | 1.38 | 1.28 |
| **Median** | **2.42** | **1.44** |

All six held-out plants improve. On the training blocks themselves the
shared clock is slightly worse than static fits (median 2.00 vs 1.78 deg),
so the clock is not a universal improvement; it specifically rescues the
block the static model fails on.

**Status:** circadian gating is a supported Model v2 candidate, not an
accepted model revision. Outstanding before any adoption: (i) a full
48-plant refit under a shared clock with the official bounds, (ii) a
head-to-head against the rival biphasic-memory-kernel candidate under
identical held-out criteria (the clock predicts dependence on absolute
ZT; the kernel predicts dependence on elapsed time since stimulus onset),
and (iii) preregistered acceptance thresholds, consistent with the
reporting standards in the README.

## 3. Verification performed

- Backward compatibility: gamma = 0 / a = 0 reproduces `sim.py` to
  machine precision on a parameter grid (`check_model_v2.py`).
- Numerical anchors: ZT9-1 clock RMSE 3.204 and static RMSE 6.759
  reproduced through an independent fitting path.
- Segment residuals and headline results of `zt9_diagnostics.py`,
  `vector_stimulus.py` and `vector_grand_atlas.py` re-derived on the
  current main and confirmed unchanged.
